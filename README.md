# Simulador de Aposentadoria - Cláudia Brea

Ferramenta web interativa de planejamento financeiro desenvolvida para captação de leads (atração de clientes) de planejamento de aposentadoria, com foco na construção de patrimônio e na fase de desfrute (saques).

## 🚀 Funcionalidades
- **Simulação Personalizada:** Cálculo detalhado de juros compostos com base na idade atual, idade de aposentadoria e renda mensal desejada.
- **Gráfico Interativo:** Visualização em tempo real das fases de Acumulação e Desfrute do patrimônio.
- **Captura de Leads:** Formulário integrado para armazenamento automático de contatos (Nome, E-mail, WhatsApp e dados financeiros) em Planilhas Google (Google Sheets).
- **Conversão Direta:** CTA otimizado direcionando o cliente para atendimento personalizado via WhatsApp.

## 🛠️ Tecnologias Utilizadas
- HTML5, CSS3 e JavaScript (Vanilla)
- Chart.js (para renderização dos gráficos dinâmicos)
- Google Apps Script (integração do formulário com o Google Sheets)
- Hospedagem gratuita via GitHub Pages
